# Frontend Design Skill

Create interfaces that feel custom-designed and production-ready, not generic templates.

For Gaurav Dubey's portfolio, emphasize distributed systems, backend engineering, cloud-native systems, full-stack engineering, reliability, scale, and AI-assisted engineering.

Prioritize content clarity, hierarchy, spacing, typography, responsiveness, accessibility, performance, then decoration.

Use a dark-first premium engineering aesthetic with near-black surfaces, restrained accents, thin borders, subtle gradients, strong sans-serif typography, monospace technical metadata, and technical grid/network motifs.

Avoid Bootstrap-like layouts, stock developer illustrations, excessive glassmorphism, rainbow gradients, excessive neon, visual clutter, and over-rounded components.

Prefer a strong hero, large headings, compact copy, intentional asymmetric layouts, clear section hierarchy, content-driven cards, and progressive disclosure.

Prefer lightweight SVG/CSS system visualizations over heavy 3D. A conceptual flow may be Client → API → Services → Event Stream → Processing → Storage → Observability.

Use reusable components and keep portfolio data separate from presentation where practical.

Before finishing a UI pass, check desktop/mobile composition, section rhythm, heading hierarchy, contrast, alignment, empty space, and whether effects distract from content.
