# Motion Design Skill

Make the portfolio feel alive and premium without making it slow, noisy, or gimmicky.

Prefer:
1. CSS transitions for simple state changes
2. CSS keyframes for simple ambient effects
3. SVG animation for architecture/network visuals
4. Motion for React for scroll, stagger, layout, and interaction choreography

Typical timing:
- 150–250ms micro-interactions
- 200–400ms component transitions
- 300–600ms section reveals
- Slow subtle ambient loops

Use hero entrance, scroll reveals, metric counters, timeline progression, architecture data-flow, card hover, and active navigation motion when useful.

Prefer transform and opacity. Avoid constant motion, large parallax, long blocking animations, expensive filters, and huge DOM animation.

Always honor prefers-reduced-motion. Disable ambient loops, cursor effects, parallax, and large movement when reduced motion is requested.

Custom cursor is optional, desktop-only, subtle, and never required for navigation.
